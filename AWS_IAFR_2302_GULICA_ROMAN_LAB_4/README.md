## Шаг 2. Создание бакетов
**Контрольный вопрос**
1. Чем отличаются два способа управления доступом к бакетам в S3?<br>

`ACL` - это старый и простой способ:<br>
- Права задаются прямо у бакета и файлов<br>
- Можно легко открыть доступ "всем"<br>
- Часто приводит к ошибкам и небезопасен<br>

`Object Ownership Enforced` - это новый и безопасный способ:<br>
- ACL отключены<br>
- Все файлы принадлежат владельцу <br>
- Доступ настраивается через политики (IAM, bucket policy)<br>

2. Первый способ с использованием `ACL`.<br>
Публичный бакет:<br>
- Имя: `cc-lab4-pub-k14`
- Region: `eu-east-1`
- Object `Ownership: ACLs enabled`
- Block all public access: `снять галочку`
- `Подтверждаю предупреждение`<br>

3. Нажимаю `Create bucket`<br>
![BAC_3](screenshots/BAC_3.png)<br>
![BAC_1](screenshots/BAC_1.png)<br>

**Контрольный вопрос**
Что означает опция `Block all public access` и зачем нужна данная настройка?<br>
`Block all public access` это настройка `S3`, которая полностью запрещает публичный доступ к бакету и его объектам.<br>

Что она делает:<br>
- Блокирует публичные ACL<br>
- Блокирует политики бакета с доступом для Everyone<br>
- Даже если случайно открыть доступ - он не сработает<br>

Зачем нужна:<br>
- Чтобы файлы не стали публичными по ошибке<br>
- Защищает данные от утечек<br>

4. Аналогично создаю приватный бакет с именем `cc-lab4-priv-k14`, но оставляю все настройки по умолчанию `Block all public access` - включен.<br>

например: `photo.jpg`<br>

**Контрольный вопрос**
В чём разница между командами `aws s3 cp`, `mv` и `sync` и для чего используется параметр флаг `--acl public-read`?<br>

`aws s3 cp` - копирует файл<br>
- из компьютера в S3, из S3 на компьютер или внутри S3<br>
- Исходный файл остаётся<br>

`aws s3 mv` - перемещает файл<br>
- после выполнения исходный файл удаляется<br>

`aws s3 sync` - синхронизирует папки<br>
- копирует только новые или изменённые файлы<br>

Для чего нужен флаг `--acl public-read`<br>
- Делает загружаемый объект публично доступным<br>
- Любой пользователь может читать файл по ссылке<br>

**Контрольный вопрос**
Что произойдёт, если выключить версионирование после его включения?<br>
Старые версии не удаляются - все уже созданные версии объектов сохраняются<br>

Новые версии больше не создаются<br>
При перезаписи файла будет использоваться одна текущая версия<br>
Удаление файла создаёт delete marker, но старые версии всё равно остаются<br>

**Контрольный вопрос**
Что такое Storage Class в Amazon S3 и зачем они нужны?<br>
В S3 Storage Class это класс хранения объекта, который определяет:<br>
- стоимость хранения
- доступность (насколько быстро можно получить файл)
- надёжность (как долго и безопасно хранится)<br>

Зачем нужны:<br>
- Чтобы экономить деньги
- Чтобы подбирать класс под нужды (частый доступ, архив, резерв)
- Чтобы оптимизировать скорость и стоимость<br>
